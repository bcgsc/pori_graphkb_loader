# Loaders

## Ontologies

| Loader                     | Description                                                                                                                    | Implementation | Documentation                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------- | ------------------------------------------------------- |
| ChEMBL                     | Loads drug and bioactive compound information from the ChEMBL database through its REST API.                                   | JavaScript     | [ChEMBL](./chembl/README.md)                            |
| Disease Ontology           | Loads standardized human disease terms and their ontology relationships from the Human Disease Ontology.                       | JavaScript     | [Disease Ontology](./disease_ontology/README.md)        |
| DrugBank                   | Loads drug names, identifiers, metadata, and cross-references from the DrugBank database.                                      | JavaScript     | [DrugBank](./drugbank/README.md)                        |
| Ensembl                    | Loads human gene, transcript, and protein identifiers and mappings from Ensembl BioMart.                                       | JavaScript     | [Ensembl](./ensembl/README.md)                          |
| Entrez Utilities           | Loads records by identifier from NCBI Entrez services for use by other loaders.                                                | JavaScript     | [Entrez Utilities](./entrez/README.md)                  |
| FDA SRS                    | Loads FDA Substance Registration System substance names, identifiers, and UNII mappings.                                       | JavaScript     | [FDA SRS](./fda-srs/README.md)                          |
| FDA Approval Announcements | Loads FDA oncology approval announcements as evidence records for use in GraphKB statements.                                   | JavaScript     | [FDA Approval Announcements](./fda_approvals/README.md) |
| HGNC                       | Loads official human gene symbols, names, identifiers, and aliases from the HGNC database.                                     | JavaScript     | [HGNC](./hgnc/README.md)                                |
| NCIt                       | Loads terminology and relationships from the NCI Thesaurus, including mappings between NCIt concepts and FDA UNIIs.            | JavaScript     | [NCIt](./ncit/README.md)                                |
| OncoTree                   | Loads the MSK OncoTree cancer classification, including tumour-type hierarchy, historical versions, and NCIt cross-references. | JavaScript     | [OncoTree](./oncotree/README.md)                        |
| GraphKB Ontology JSON      | Loads locally defined vocabularies and ontologies represented in GraphKB's custom JSON ontology format.                        | JavaScript     | [GraphKB Ontology JSON](./ontology/README.md)           |
| RefSeq                     | Loads NCBI RefSeq reference transcript identifiers and associated gene mappings.                                               | JavaScript     | [RefSeq](./refseq/README.md)                            |
| Uberon                     | Loads anatomical terms and relationships from the Uberon cross-species anatomy ontology.                                       | JavaScript     | [Uberon](./uberon/README.md)                            |

## Knowledge Bases

| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- | ---------------------------------------------------------------- |

| CGL                       | Loads internally curated Genome Sciences Centre knowledge statements into GraphKB.                                                                                                     | JavaScript     | [CGL](./cgl/README.md)                                           |
| CIViC                     | Loads community-curated clinical evidence linking molecular variants, diseases, therapies, and clinical outcomes from CIViC.                                                           | JavaScript     | [CIViC](./civic/README.md)                                       |

| COSMIC                    | Loads cancer-associated gene fusions and drug-resistance mutations from the COSMIC database.                                                                                           | JavaScript     | [COSMIC](./cosmic/README.md)                                     |
| DGIdb                     | Loads curated and aggregated drug–gene interactions from the Drug–Gene Interaction Database.                                                                                           | JavaScript     | [DGIdb](./dgidb/README.md)                                       |

| PMC4468049                | Loads the supplementary pan-cancer catalogue of TCGA fusion transcripts reported by Yoshihara et al.                                                                                   | JavaScript     | [PMC4468049](./PMC4468049/README.md)                             |
| PMC4232638                | Loads the supplementary set of functionally characterized cancer-related missense variants compiled by Martelotto et al.                                                               | JavaScript     | [PMC4232638](./PMC4232638/README.md)                             |
